# ScoreBoard

The end of a round (`ScoreBoard.jsx`): the percentage inside a ring of 20 bulbs (lit = share correct), the grade word as the poster headline, points, and results per topic.

- Grade word in `display` in the pen, with the kicker *Das war* — *Fantastisch!* (≥90), *Super!* (≥75), *Gut gemacht!* (≥60), *Nicht schlecht!* (≥40), *Weiter üben!*.
- Topic rows: ≥80 % olive + check, 50–79 % cream + repeat, <50 % ochre + cross.
- Highscore table below in a plain `vx-card`.
