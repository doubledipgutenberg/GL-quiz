# Icons

24×24 line icons, 2.25px round strokes, single ink **#1F45A8**. In the UI use them as masks (`<i class="vx-ico vx-ico--speaker">`) so they take `currentColor` and follow the course pen. lucide-react icons at `strokeWidth={2.25}` sit alongside them.

check · cross — answer states only. speaker — audio (replaces 🔊). lightbulb — Tipp. grammar · book · repeat · signpost — quiz modes and exams. star · streak-flame — points. pencil — typed answer. arrow-right — Weiter / choices.
