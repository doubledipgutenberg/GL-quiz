# StreetSign

Headers for an exam or unit, styled as street plaques: blue enamel for French (Paris), a white plaque with a red rule for English (London).

- Shows the chosen *Schulaufgabe* at the top of step 3 (*Wie willst du üben?*) and on the score screen.
- Name = unit title (`EXAMS[id].units` or the book unit name), 1–3 words. Small line = exam label.
- The plaque always uses its own city's pen, whatever `data-course` says.
