# RoundProgress

Progress inside a review round: the ProgressLights meta line with the round added, the plain track bar (50 cards are too many for string lights) and one line of what comes after.

- Meta: *Runde 8 von 9 · Karte 12 von 50* left, points right.
- Note under the bar: *Danach noch 2 Runden.* / *Danach noch 1 Runde – dann bist du durch.* / on the last round *Letzte Runde – gleich geschafft!*
- Normal quizzes (15 questions) keep ProgressLights.
