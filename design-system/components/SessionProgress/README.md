# SessionProgress

Progress inside a review session: the ProgressLights meta line with the session added, the plain track bar (50 cards are too many for string lights) and one line of what comes after.

- Meta: *Session 8 von 9 · Karte 12 von 50* left, points right.
- Note under the bar: *Danach noch 2 Sessions.* / *Danach noch 1 Session – dann bist du durch.* / on the last session *Letzte Session – gleich geschafft!*
- Normal quizzes (15 questions) keep ProgressLights.
