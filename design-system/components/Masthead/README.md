# Masthead

The app's name as a poster headline: a two-colour awning, the handwritten kicker *Clara & Jakob lernen* over the display word **SPRACHEN**, and the class + greeting underneath.

- Replaces the `Quiz Challenge` header in `WelcomeScreen.jsx` and sits on the login screen.
- The awning alternates `fr-pen` and `en-pen` stripes — the only place both pens appear together.
- The display word is in `ink` (house screens have no course yet). Greeting line: `label` style, `Klasse 6d · Hallo {Name}!`.
